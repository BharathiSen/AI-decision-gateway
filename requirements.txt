# Network emulation runs entirely on the Mininet Python API, which
# ships with the system-wide Mininet install and is NOT installed via
# pip. In the Ubuntu VM, if Mininet isn't already installed:
#
#   git clone https://github.com/mininet/mininet
#   mininet/util/install.sh -a
#
# This must be run with the VM's system Python (not a virtualenv),
# since the mininet package is installed system-wide alongside
# Open vSwitch.
#
# Nothing else is required for the network/telemetry layer.
#
# The AI decision agent calls Groq (OpenAI-API-compatible) via the
# OpenAI SDK, pointed at https://api.groq.com/openai/v1. Needs a real key
# in the environment (GROQ_API_KEY, starts gsk_). LLM_PROVIDER=grok (xAI),
# openrouter or gemini switches backends. Unlike the
# network/telemetry layer, this has no dependency on Mininet/Linux and
# can run anywhere Python and this package are installed. It also
# loads its policy context from policy/policy.yaml, hence pyyaml.
# Exact versions: an unpinned SDK runs as root next to the network controller.
# These are the versions the offline suite was run against (2026-11-12).
# Confirm `pip show openai pyyaml` on the VM before reinstalling there.
openai==2.45.0
pyyaml==6.0.3
